# S2-04: Implement event handler code generation

**Story ID:** S2-04
**Status:** Pending
**Epic:** MVP 2 - Rendering Engine
**Points:** 5

## Description

Generate code for event handlers like `on_click`, `on_input`, etc. Use native browser events with wasm-bindgen Closures.

## Acceptance Criteria

- [ ] Parse event attributes: `on_click`, `on_input`, `on_change`, etc.
- [ ] Generate `Closure::new` wrapper for handler
- [ ] Call `element.set_onclick(Some(&closure))`
- [ ] Clone captured variables into closure
- [ ] Prevent memory leaks (into_js_value())
- [ ] Unit tests for:
  - Single event handler
  - Multiple handlers on same element
  - Handler captures state

## Implementation Notes

- Extend `domius-macro/src/codegen.rs`
- Use `wasm-bindgen` Closure API
- Event names: click → onclick, input → oninput, change → onchange
- Use `forget()` on Closure to prevent auto-drop

## Code Structure

```rust
// Input
domus! { button(on_click: |_| signal.set(true)) { "Click" } }

// Generated
let __signal = signal.clone();
let __handler = Closure::new(move |_: web_sys::MouseEvent| {
    __signal.set(true);
});
__el.set_onclick(Some(__handler.as_ref().unchecked_ref()));
__handler.forget();
```
