## Description

Implement context provider and consumer functions to share state without prop drilling. Uses TypeId for type-safe lookups.

## Acceptance Criteria

## Implementation Notes

- Place in `domius-web/src/context.rs`
- Context stored in `thread_local!` registry
- Use `std::any::TypeId` for lookup
- Scopes have parent links for hierarchy

## Code Structure

```rust
thread_local! {
    static CONTEXT_REGISTRY: RefCell<HashMap<TypeId, Box<dyn Any>>>
        = RefCell::new(HashMap::new());
}

pub fn provide_context<T: 'static>(value: T) {
    CONTEXT_REGISTRY.with(|reg| {
        reg.borrow_mut().insert(TypeId::of::<T>(), Box::new(value));
    });
}

pub fn use_context<T: 'static>() -> Option<T> {
    CONTEXT_REGISTRY.with(|reg| {
        reg.borrow()
            .get(&TypeId::of::<T>())
            .and_then(|v| v.downcast_ref::<T>().map(|t| t.clone()))
    });
}
```

## Testing Strategy

```rust
#[test]
fn test_context_sharing() {
    #[derive(Clone)]
    struct AuthContext { user: String }

    provide_context(AuthContext { user: "alice".into() });
    let ctx = use_context::<AuthContext>();
    assert_eq!(ctx.unwrap().user, "alice");
}
```
