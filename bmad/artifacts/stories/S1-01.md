# S1-01: Set up Cargo workspace and crate structure

**Story ID:** S1-01 (Sprint 1, Story 1)
**Status:** In Progress
**Epic:** MVP 1 - Reactive Core
**Points:** 3

## Description

Create the foundational Cargo workspace with the four main crates:
- `domus-core` — Signals, Effects, and runtime
- `domus-macro` — Procedural macro for `domus!`
- `domus-web` — Component system and DOM bindings
- `domus-cli` — Code generation tool

## Acceptance Criteria

- [ ] Root `Cargo.toml` configured as workspace with 4 members
- [ ] `domus-core/Cargo.toml` created with dependencies:
  - `wasm-bindgen`
  - `web-sys` (with DOM features)
  - `js-sys`
- [ ] `domus-macro/Cargo.toml` created with dependencies:
  - `proc-macro2`
  - `syn`
  - `quote`
- [ ] `domus-web/Cargo.toml` created with `domus-core` as dependency
- [ ] `domus-cli/Cargo.toml` created as binary
- [ ] All crates compile without warnings
- [ ] Each crate has `src/lib.rs` with module declarations

## Implementation Notes

- Use `cargo-generate` or manual setup
- Configure for WASM target: `wasm32-unknown-unknown`
- Add `.cargo/config.toml` with opt-level = 3 for release builds
- Create `examples/` directory structure
