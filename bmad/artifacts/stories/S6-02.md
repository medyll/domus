# S6-02: Implement MutationObserver-based disposal

**Story ID:** S6-02
**Status:** Pending
**Epic:** MVP 6 - Memory Management
**Points:** 5

## Description

Use browser's MutationObserver API to detect when elements are removed from DOM and trigger automatic scope disposal and cleanup.

## Acceptance Criteria

- [ ] MutationObserver watches document for removals
- [ ] Detects elements with `data-domus-scope` attribute
- [ ] Triggers `dispose_scope()` on removal
- [ ] Unsubscribes all effects from signals
- [ ] Frees WASM memory
- [ ] Zero false positives
- [ ] Integration tests

## Implementation Notes

- Place in `domus-web/src/disposal.rs`
- Initialize observer on app startup
- Watch entire document
- Use `element.closest('[data-domus-scope]')` to find scope

## Code Structure

```rust
pub fn init_disposal_observer() {
    let observer = MutationObserver::new(|mutations| {
        for mutation in mutations {
            if let Some(removed) = mutation.removed_nodes() {
                for i in 0..removed.length() {
                    if let Some(node) = removed.get(i) {
                        // Check for data-domus-scope
                        if let Some(element) = node.dyn_ref::<web_sys::Element>() {
                            if let Ok(Some(scope_str)) = element.get_attribute("data-domus-scope") {
                                let scope_id: ScopeId = scope_str.parse().unwrap();
                                dispose_scope(scope_id);
                            }
                        }
                    }
                }
            }
        }
    });

    let options = MutationObserverInit::new();
    options.set_subtree(true);
    options.set_child_list(true);
    observer.observe_with_options(&web_sys::window().unwrap().document().unwrap(), &options);
}
```

## Testing Strategy

```rust
#[test]
fn test_disposal_on_removal() {
    let signal = signal(0);
    let scope = create_scope(None);

    let signal_clone = signal.clone();
    create_effect_in_scope(scope, move || {
        signal_clone.get();
    });

    // Element removed
    element.remove();

    // Scope should be disposed
    assert_eq!(get_scope(scope), None);
}
```
