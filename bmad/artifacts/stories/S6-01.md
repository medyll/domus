# S6-01: Implement domus-cli basic commands

**Story ID:** S6-01
**Status:** Pending
**Epic:** MVP 6 - CLI & Production
**Points:** 8

## Description

Create the command-line tool `domus-cli` that automates project scaffolding and component generation.

## Acceptance Criteria

- [ ] `domus new project <name>` — creates project structure
- [ ] `domus add component <name>` — generates component folder
- [ ] `domus add page <name>` — generates page with controller.rs, view.rs
- [ ] `domus dev` — starts dev server with watch
- [ ] `domus build --release` — production build
- [ ] Boilerplate generation (actual working code)
- [ ] Route registration automation
- [ ] Integration tests for each command

## Implementation Notes

- Place in `domus-cli/src/`
- Use `clap` for CLI argument parsing
- Templates in `domus-cli/templates/`
- Generate actual Rust code (not placeholders)
- Auto-register pages in routes.rs

## Code Structure

```rust
// main.rs
use clap::{Parser, Subcommand};

#[derive(Parser)]
struct Args {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    New { project_name: String },
    Add { what: String, name: String },
    Dev,
    Build,
}
```

## Testing Strategy

```rust
#[test]
fn test_new_project() {
    let tmpdir = TempDir::new().unwrap();
    let result = Command::new("domus")
        .arg("new")
        .arg("project")
        .arg("test-app")
        .current_dir(&tmpdir)
        .output()
        .unwrap();

    assert!(result.status.success());
    assert!(Path::new("test-app/Cargo.toml").exists());
}
```
