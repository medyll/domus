# S5-03: Implement Scoped CSS system

**Story ID:** S5-03
**Status:** Pending
**Epic:** MVP 5 - Advanced Features

## Description

Implement automatic CSS scoping where component styles are prefixed with a unique `data-domus-{hash}` attribute. This prevents style conflicts across components.

## Acceptance Criteria

- [ ] Hash generation from component path + content
- [ ] Generate unique `data-domus-{hash}` attribute
- [ ] Macro injects attribute on root element
- [ ] CLI transforms CSS selectors to scoped versions
- [ ] CSS compilation step: `.btn { ... }` → `[data-domus="hash"] .btn { ... }`
- [ ] Integration with component folder structure
- [ ] Unit tests for scoping

## Implementation Notes

- Place in `domius-cli/src/css_scoper.rs`
- Hash using SHA256 first 4 chars
- Macro queries for `style.css` in component folder
- CSS parser can be simple regex-based for MVP

## Code Structure

```rust
pub fn scope_css(css: &str, scope_hash: &str) -> String {
    // Transform: .btn { color: red; }
    // Into: [data-domus="abc1"] .btn { color: red; }
    let scoped = format!("[data-domus=\"{}\"] {}", scope_hash, css);
    scoped
}

pub fn generate_scope_hash(path: &str, content: &str) -> String {
    use sha2::{Sha256, Digest};
    let mut hasher = Sha256::new();
    hasher.update(path);
    hasher.update(content);
    let result = hasher.finalize();
    format!("{:x}", result)[..4].to_string()
}
```

fn test_css_scoping() {
    let css = ".btn { color: red; }";

}
