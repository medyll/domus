# S3-01: Implement DomusComponent trait

**Story ID:** S3-01
**Status:** Pending
**Epic:** MVP 3 - Components
**Points:** 5

## Description

Define the core `DomusComponent` trait that all components must implement. This establishes the contract between the framework and user components.

## Acceptance Criteria

- [ ] `DomusComponent` trait with:
  - `type Props`
  - `type State`
  - `fn setup(props: Self::Props) -> Self::State`
  - `fn render(state: &Self::State) -> DomusNode`
- [ ] `DomusNode` type to represent rendered elements
- [ ] Derive macros or helpers for boilerplate
- [ ] Example implementations (Button, Counter)
- [ ] Unit tests for trait usage
- [ ] Documentation with examples

## Implementation Notes

- Place in `domus-web/src/component.rs`
- `DomusNode` is likely just `web_sys::Element` or wrapper
- Provide helper functions for common patterns
- This is the public API, must be stable

## Code Structure

```rust
pub trait DomusComponent {
    type Props;
    type State;

    fn setup(props: Self::Props) -> Self::State;
    fn render(state: &Self::State) -> DomusNode;
}

pub type DomusNode = web_sys::Element;
```

    type Props = ButtonProps;
    type State = ();

    fn setup(_props: Self::Props) -> Self::State { () }
    fn render(_state: &Self::State) -> DomusNode {
        domus! { button { "Click" } }
    }
}
