# S2-02: Implement code generation for static elements

**Story ID:** S2-02
**Status:** Pending
**Epic:** MVP 2 - Rendering Engine
**Points:** 5

## Description

Generate Rust code from the RSX AST that creates DOM elements using `web-sys`. Handle static elements first (no dynamic bindings).

## Acceptance Criteria

- [ ] Code generation for `document.create_element(tag)`
- [ ] Attribute setting: `element.set_attribute(name, value)`
- [ ] Child appending: `element.append_child(child)`
- [ ] Text node creation: `document.create_text_node(text)`
- [ ] Proper error handling on DOM operations
- [ ] Variable hygiene (use `__` prefix)
- [ ] Generated code compiles and runs
- [ ] Unit tests verify generated TokenStream

## Implementation Notes

- Place in `domius-macro/src/codegen.rs`
- Use `quote!` macro for code generation
- Each element gets unique variable name: `__el_0`, `__el_1`, etc.
- Use `web_sys::window().unwrap().document().unwrap()`
- No Effects yet (S2-03)

## Code Structure

```rust
pub fn generate_static(node: &RsxNode) -> TokenStream {
    match node {
        RsxNode::Element { tag, attrs, children } => {
            let el_var = format!("__el_{}", counter());
            quote! {
                let #el_var = web_sys::window()
                    .unwrap()
                    .document()
                    .unwrap()
                    .create_element(#tag)
                    .unwrap();
                // set attributes
                // append children
                #el_var
            }
        }
        RsxNode::Text(content) => {
            quote! {
                web_sys::window()
                    .unwrap()
                    .document()
                    .unwrap()
                    .create_text_node(#content)
            }
        }
        _ => panic!("Dynamic elements in S2-03"),
    }
}
```
