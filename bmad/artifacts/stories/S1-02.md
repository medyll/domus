# S1-02: Implement Signal<T> core type

**Story ID:** S1-02
**Status:** Pending
**Epic:** MVP 1 - Reactive Core
**Points:** 5

## Description

Implement the fundamental `Signal<T>` type that stores reactive state and notifies subscribers. This is the cornerstone of Domus's reactivity system.

## Acceptance Criteria

- [ ] `Signal<T>` struct defined with:
  - `value: Rc<RefCell<T>>`
  - `subscribers: Rc<RefCell<Vec<Rc<Effect>>>>`
- [ ] `signal(value: T) -> Signal<T>` constructor
- [ ] `Signal::get(&self) -> T` with auto-tracking
- [ ] `Signal::set(&self, new_val: T)` with notification
- [ ] `Signal::update<F>(&self, f: F)` for mutations
- [ ] Prevents duplicate subscriptions (uses `Rc::ptr_eq`)
- [ ] Clone implementation for sharing between components
- [ ] Unit tests for:
  - Basic get/set operations
  - Subscription tracking (verified by Effect calls)
  - Clone independence
  - Multiple subscribers

## Implementation Notes

- Place in `domus-core/src/signal.rs`
- Use `Rc<RefCell<T>>` for interior mutability (WASM is single-threaded)
- Effect type is forward-declared; don't import yet (circular dependency)
- TLS integration will come in S1-03
- Implement `Clone` manually to avoid trait bounds on `T`
