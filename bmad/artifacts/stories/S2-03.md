# S2-03: Implement code generation for dynamic bindings

**Story ID:** S2-03
**Status:** Pending
**Epic:** MVP 2 - Rendering Engine
**Points:** 8

## Description

Extend code generation to handle dynamic expressions in `{}`. For each dynamic binding, generate an `Effect` that automatically updates the DOM when the reactive value changes. This includes dynamic text content, dynamic attributes, and dynamic attribute values.

## Acceptance Criteria

- [ ] Dynamic text nodes: `{signal}` generates `Effect` updating `set_text_content`
- [ ] Dynamic attributes: `attr: {signal}` generates `Effect` updating `set_attribute`
- [ ] Auto-cloning: Signals automatically cloned into closures (no manual `.clone()`)
- [ ] Multiple dynamics: `{a} ... {b}` each get separate Effects
- [ ] Closure capture: Variables correctly moved into `move ||` closures
- [ ] Variable hygiene: Generated variables use `__` prefix to avoid collisions
- [ ] No performance regression: Static elements still generate zero Effects
- [ ] Unit tests for:
  - Single dynamic text
  - Multiple dynamic bindings in one element
  - Dynamic attributes
  - Mixed static and dynamic content

## Implementation Notes

**Key Challenge:** Auto-detecting which identifiers need cloning

**Strategy:**
1. After generating code, scan the closure body for identifier usage
2. For each identifier found, check if it's a `Signal<T>` type (heuristic: if it has `.get()` method calls)
3. If yes, generate `let {ident}_clone = {ident}.clone();` before the closure

**Decision Points:**
- **Auto-clone strategy:** Parse closure body AST to find identifier references
- **Error handling:** If identifier not found in scope, emit helpful error
- **Performance:** Cache which variables are Signals to avoid repeat checks

## Detailed Algorithm

### Phase 1: Collect Dynamic Nodes

```
SCAN_AST(node):
  1. If RsxNode::Dynamic:
     - Record: expression, parent node, position
  2. If RsxNode::Element:
     - For each attribute value:
       - If RsxAttr::Dynamic: record as dynamic attribute
     - Recursively scan children

RESULT: Vec<DynamicBinding> {
    type: TextContent | Attribute,
    expr: Expr,
    parent_elem: NodeId,
    attr_name: Option<String>,  // for attributes
}
```

### Phase 2: Identify Variables Needing Clone

```
ANALYZE_EXPR(expr: &Expr) -> Vec<String>:
  1. Walk expr AST
  2. Collect all Path::Ident references
  3. Filter out:
     - Literals, keywords (true, false, etc)
     - Local bindings (|x| x - don't clone)
     - Method names (.get(), etc)
  4. Return unique identifiers

RESULT: ["signal", "count", "theme"]  // Variables to clone
```

### Phase 3: Generate Effect Code

```
For each DynamicBinding:

  1. Create unique variable names:
     - Element: __el_{counter}
     - Dynamic node: __dyn_{counter}
     - Clones: {ident}_clone for each ident

  2. If TextContent:
     ```rust
     let __dyn_0 = document.create_text_node("");
     __el_parent.append_child(&__dyn_0).unwrap();

     let signal_clone = signal.clone();
     domus::create_effect(move || {
         __dyn_0.set_text_content(Some(&signal_clone.get().to_string()));
     });
     ```

  3. If Attribute:
     ```rust
     let signal_clone = signal.clone();
     domus::create_effect(move || {
         __el.set_attribute("class", &signal_clone.get()).unwrap();
     });
     ```

  4. Return generated tokens
```

```rust
// domius-macro/src/codegen.rs

/// Represents a dynamic binding to be generated
struct DynamicBinding {
    kind: BindingKind,
    expr: Expr,
    parent_id: String,
    attr_name: Option<String>,
}

enum BindingKind {
    TextContent,
    Attribute,
}

/// Generate code for all dynamic bindings
pub fn generate_dynamic_bindings(
    bindings: Vec<DynamicBinding>,
) -> TokenStream {
    let mut generated = TokenStream::new();

    for (idx, binding) in bindings.iter().enumerate() {
        let vars_to_clone = analyze_expr(&binding.expr);
        let clone_stmts = generate_clones(&vars_to_clone);

        match binding.kind {
            BindingKind::TextContent => {
                generated.extend(generate_text_effect(&binding, idx, clone_stmts));
            }
            BindingKind::Attribute => {
                generated.extend(generate_attr_effect(&binding, idx, clone_stmts));
            }
        }
    }

    generated
}

/// Generate clones: let signal_clone = signal.clone();
fn generate_clones(vars: &[String]) -> TokenStream {
    let clones = vars.iter().map(|var| {
        let clone_var = format_ident!("{}_clone", var);
        let orig_var = format_ident!("{}", var);
        quote! {
            let #clone_var = #orig_var.clone();
        }
    });
    quote! { #(#clones)* }
}

/// Generate Effect for text content
fn generate_text_effect(
    binding: &DynamicBinding,
    idx: usize,
    clones: TokenStream,
) -> TokenStream {
    let dyn_var = format_ident!("__dyn_{}", idx);
    let parent_var = format_ident!("{}", binding.parent_id);
    let expr = &binding.expr;

    // Map original vars to clones in the closure
    let expr_with_clones = substitute_clones(expr);

    quote! {
        let #dyn_var = web_sys::window()
            .unwrap()
            .document()
            .unwrap()
            .create_text_node("");
        #parent_var.append_child(&#dyn_var).unwrap();

        #clones
        domus::create_effect(move || {
            let value = #expr_with_clones.get().to_string();
            #dyn_var.set_text_content(Some(&value));
        });
    }
}

/// Generate Effect for attribute
fn generate_attr_effect(
    binding: &DynamicBinding,
    idx: usize,
    clones: TokenStream,
) -> TokenStream {
    let el_var = format_ident!("{}", binding.parent_id);
    let attr_name = binding.attr_name.as_ref().unwrap();
    let expr = &binding.expr;
    let expr_with_clones = substitute_clones(expr);

    quote! {
        #clones
        domus::create_effect(move || {
            let value = #expr_with_clones.get();
            #el_var.set_attribute(#attr_name, &value).unwrap();
        });
    }
}

/// Replace original vars with cloned versions in expression
fn substitute_clones(expr: &Expr) -> Expr {
    // Walk expr, replace path::ident with path::ident_clone
    // E.g., `signal.get()` → `signal_clone.get()`
    // This is a simplified AST transformation
    expr.clone() // TODO: implement substitution
}

/// Extract all identifiers used in expression
fn analyze_expr(expr: &Expr) -> Vec<String> {
    let mut vars = Vec::new();
    collect_idents(expr, &mut vars);
    vars.into_iter().unique().collect()
}

fn collect_idents(expr: &Expr, vars: &mut Vec<String>) {
    match expr {
        Expr::Path(p) => {
            if let Some(ident) = p.path.get_ident() {
                vars.push(ident.to_string());
            }
        }
        Expr::MethodCall(m) => {
            collect_idents(&m.receiver, vars);
            // Don't add method name as variable
        }
        Expr::Call(c) => {
            collect_idents(&c.func, vars);
            for arg in &c.args {
                collect_idents(arg, vars);
            }
        }
        Expr::Field(f) => {
            collect_idents(&f.base, vars);
        }
        // ... handle other expr types
        _ => {}
    }
}

## Concrete Examples

### Example 1: Dynamic Text

**Input:**
```rust
domus! {
    span { "Count: " {count_signal} }
}
```

**Generated Code:**
```rust
{
    let __el_0 = document.create_element("span").unwrap();
    let __text_0 = document.create_text_node("Count: ");
    __el_0.append_child(&__text_0).unwrap();

    let __dyn_0 = document.create_text_node("");
    __el_0.append_child(&__dyn_0).unwrap();

    let count_signal_clone = count_signal.clone();
    domus::create_effect(move || {
        let value = count_signal_clone.get().to_string();
        __dyn_0.set_text_content(Some(&value));
    });

    __el_0
}
```

### Example 2: Dynamic Attribute

**Input:**
```rust
domus! {
    button(class: {theme}) { "Click" }
}
```

**Generated Code:**
```rust
{
    let __el_0 = document.create_element("button").unwrap();

    let theme_clone = theme.clone();
    domus::create_effect(move || {
        let value = theme_clone.get();
        __el_0.set_attribute("class", &value).unwrap();
    });

    let __text_0 = document.create_text_node("Click");
    __el_0.append_child(&__text_0).unwrap();

    __el_0
}
```

### Example 3: Multiple Dynamics

**Input:**
```rust
domus! {
    div {
        p { {first} " " {last} }
        button(class: {is_active}) { {button_label} }
    }
}
```

**Generated Code:**
```rust
{
    let __el_0 = document.create_element("div").unwrap();

    // Paragraph with two dynamic texts
    let __el_1 = document.create_element("p").unwrap();
    let first_clone = first.clone();
    domus::create_effect(move || {
        __dyn_1.set_text_content(Some(&first_clone.get().to_string()));
    });
    __el_1.append_child(&__dyn_1).unwrap();

    let __text_2 = document.create_text_node(" ");
    __el_1.append_child(&__text_2).unwrap();

    let last_clone = last.clone();
    domus::create_effect(move || {
        __dyn_2.set_text_content(Some(&last_clone.get().to_string()));
    });
    __el_1.append_child(&__dyn_2).unwrap();

    __el_0.append_child(&__el_1).unwrap();

    // Button with dynamic attribute and text
    let __el_3 = document.create_element("button").unwrap();
    let is_active_clone = is_active.clone();
    domus::create_effect(move || {
        __el_3.set_attribute("class", &is_active_clone.get()).unwrap();
    });

    let button_label_clone = button_label.clone();
    domus::create_effect(move || {
        __dyn_3.set_text_content(Some(&button_label_clone.get().to_string()));
    });
    __el_3.append_child(&__dyn_3).unwrap();
    __el_0.append_child(&__el_3).unwrap();

    __el_0
}
```

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_dynamic_text_generation() {
        let binding = DynamicBinding {

## Common Pitfalls to Avoid

1. **Not cloning signals** — Effect captures `signal` directly, then `.clone()` inside closure (wrong)
2. **Variable shadowing** — Cloned var has same name as original in outer scope
3. **Wrong node target** — Updating wrong text node or attribute
4. **Missing unwrap()** — DOM operations return Option/Result
5. **Closure capture** — Variables must be `move` to capture ownership
