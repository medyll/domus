# S4-01: Implement DomusPage trait and Router

**Story ID:** S4-01
**Status:** Pending
**Epic:** MVP 4 - Routing
**Points:** 8

## Description

Create the `DomusPage` trait for pages and implement the `Router` that matches URLs and mounts/unmounts pages dynamically.

## Acceptance Criteria

- [ ] `DomusPage` trait extending `DomusComponent`:
  - `fn route() -> &'static str`
  - `fn title(state: &Self::State) -> String`
  - `async fn on_load(state: &Self::State)`
- [ ] `Router` struct that:
  - Listens for `popstate` events
  - Matches URL against registered routes
  - Unmounts old page, mounts new page
  - Calls `on_load` hook
- [ ] URL pattern matching: `/`, `/user/:id`, `*` (404)
- [ ] Route registration system
- [ ] Unit tests for matching
- [ ] Example pages (Home, NotFound)

## Implementation Notes

- Place in `domus-web/src/page.rs` and `domus-web/src/router.rs`
- Use `web_sys::window().location()` for URL
- Pattern matching algorithm (check plan-spec)
- Page transitions dispose previous scope

## Code Structure

```rust
pub trait DomusPage: DomusComponent {
    fn route() -> &'static str;
    fn title(state: &Self::State) -> String;
    async fn on_load(state: &Self::State);
}

pub struct Router {
    routes: Vec<(String, Box<dyn Fn() -> DomusNode>)>,
    current_page: Option<ScopeId>,
}

impl Router {
    pub fn navigate(&mut self, path: &str);
    pub fn match_route(&self, path: &str) -> Option<Box<dyn Fn() -> DomusNode>>;
}
```

## Testing Strategy

```rust
#[test]
fn test_route_matching() {
    let router = Router::new();
    router.register::<HomePage>("/");
    router.register::<UserPage>("/user/:id");

    assert!(router.match_route("/").is_some());
    assert!(router.match_route("/user/42").is_some());
    assert!(router.match_route("/notfound").is_none());
}
```
